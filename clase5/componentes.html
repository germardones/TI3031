Codificación por Componentes

Un componente es una pieza de interfaz reutilizable. Construir en React es como armar con LEGO: piezas pequeñas que se combinan.

1. La Idea: Piezas Reutilizables

Un componente es simplemente una función que devuelve interfaz. Una página se arma combinando muchos componentes pequeños.

Una página = árbol de componentes

<App />

<Header />

<Logo /> <NavMenu />

<ListaProductos />

<Card /> <Card /> <Card />

Fíjate: <Card /> se reutiliza 3 veces. Escribes la pieza una vez, la usas las veces que quieras.

2. Anatomía de un Componente

Este es un componente Saludo completo. Cada línea está explicada a su derecha. Es la "radiografía" que pediste: a qué hace referencia cada parte.

1
import { useState } from "react";
Importación. Trae la herramienta useState (un Hook) desde la librería React para poder usar estado.
2
Línea en blanco: solo separa la importación del código (estilo, no obligatorio).
3
function Saludo({ nombre }) {
Definición del componente. Es una función. Su nombre va en Mayúscula (regla de React). Recibe props y aquí desestructura nombre.
4
const [veces, setVeces] = useState(0);
Estado. veces guarda el valor; setVeces lo cambia. Empieza en 0. Al cambiar, React redibuja.
5
Separación visual entre la lógica (arriba) y lo que se devuelve (abajo).
6

return. Aquí empieza lo que el componente muestra en pantalla. El paréntesis permite escribir en varias líneas.
7
<div className="tarjeta">
JSX. Parece HTML pero es JavaScript. Se usa className (no class) porque class es palabra reservada de JS.
8
<h2>Hola, {nombre} 👋</h2>
Interpolación. Las llaves { } insertan un valor de JavaScript dentro del JSX. Aquí muestra la prop nombre.
9
<p>Saludado {veces} veces</p>
Muestra el valor actual del estado. Cada vez que veces cambia, este texto se actualiza solo.
10

Evento. onClick recibe una función. Al hacer clic llama a setVeces y suma 1 al estado.
11

Texto interno del botón (lo que ve el usuario).
12
</button>
Cierre del botón. Toda etiqueta abierta debe cerrarse en JSX (es más estricto que HTML).
13
</div>
Cierre del contenedor. Un componente debe devolver un solo elemento raíz.
14
);
Cierra el return ( de la línea 6.
15
}
Cierra la función del componente (línea 3).
16
Separación antes de exportar.
17

Exportación. Hace que otros archivos puedan importar y usar <Saludo />.

Resumen de las 4 partes clave

1) Imports (lo que necesitas) → 2) Función con props (datos que entran) → 3) Estado y lógica (qué puede cambiar) → 4) return con JSX (lo que se ve) → export (para reutilizarlo).

3. Props: Pasar Datos al Componente

Las props son como los argumentos de una función: datos que entran desde fuera. Permiten que el mismo componente muestre cosas distintas.

El componente (recibe props)
function Card({ titulo, precio }) {
  return (
    <div>
      <h3>{titulo}</h3>
      <p>${precio}</p>
    </div>
  );
}
El padre (envía props)
function Tienda() {
  return (
    <div>
      <Card titulo="Teclado" precio={25} />
      <Card titulo="Mouse" precio={15} />
    </div>
  );
}

Texto vs. número en props

Un texto va entre comillas: titulo="Teclado". Cualquier otro valor de JS (número, variable, booleano) va entre llaves: precio={25}.

4. Estado con useState

El estado es la memoria del componente. La diferencia clave con las props: las props vienen de fuera, el estado vive dentro y cambia.

const [veces, setVeces] = useState(0);
// ▲ valor ▲ función ▲ valor inicial

veces

El valor actual. Lo lees en el JSX.

setVeces

La única forma de cambiarlo. Nunca hagas veces = 5.

useState(0)

Valor con el que arranca.

Error típico

No modifiques el estado directamente: React no se entera y la pantalla no se actualiza.

// ❌ Mal: React no redibuja
veces = veces + 1;

// ✅ Bien: usa la función setter
setVeces(veces + 1);

5. Renderizar Listas

Para mostrar una lista de datos usas .map() (lo viste en el módulo de arreglos). Cada elemento necesita una prop key única.

const tareas = [
  { id: 1, texto: "Estudiar React" },
  { id: 2, texto: "Hacer ejercicio" }
];

return (
  <ul>
    {tareas.map((tarea) => (
      <li key={tarea.id}>{tarea.texto}</li>
    ))}
  </ul>
);
