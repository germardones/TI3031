Local Storage

El estado de React vive en memoria: al recargar, desaparece. Local Storage guarda datos en el navegador para que sobrevivan.

1. ¿Qué es Local Storage?

localStorage es una pequeña base de datos que vive en el navegador del usuario. Guarda pares clave → valor, como un diccionario que no se borra al recargar.

💾

Persiste

Sobrevive a recargas y a cerrar el navegador.

🔤

Solo texto

Únicamente guarda strings. Por eso usamos JSON.

📦

~5 MB

Límite por dominio. Ideal para preferencias, no para archivos.

⚠ Nunca guardes datos sensibles

localStorage es accesible por cualquier JavaScript de la página. No guardes contraseñas, tokens de sesión ni datos privados. Lo veremos a fondo en Desarrollo Seguro.

2. Los 4 Métodos

Toda la API de localStorage son 4 funciones. Pruébalas en la consola del navegador (F12):

localStorage.setItem(clave, valor)

Guarda un valor. Ejemplo: localStorage.setItem("tema", "oscuro")

localStorage.getItem(clave)

Lee un valor. Devuelve null si no existe. Ejemplo: localStorage.getItem("tema") → "oscuro"

localStorage.removeItem(clave)

Borra un valor concreto. Ejemplo: localStorage.removeItem("tema")

localStorage.clear()

Borra todo el almacén de ese dominio. Úsalo con cuidado.

3. Guardar Objetos: JSON

localStorage solo guarda texto. Si intentas guardar un objeto, se convierte en el inútil "[object Object]". La solución: JSON.

Guardar: objeto → texto

JSON.stringify convierte un objeto en texto.

const usuario = { nombre: "Ana", edad: 22 };

localStorage.setItem(
  "usuario",
  JSON.stringify(usuario) // → texto
);
Leer: texto → objeto

JSON.parse convierte el texto de vuelta en objeto.

const texto = localStorage.getItem("usuario");

const usuario = JSON.parse(texto);

console.log(usuario.nombre); // "Ana"

Regla de oro

stringify al guardar, parse al leer. Siempre en pareja. Si lees algo que no es JSON válido, JSON.parse lanza error: envuélvelo en try/catch en código real.

4. Local Storage en React

En React combinamos localStorage con dos Hooks: useState (para el valor inicial) y useEffect (para guardar cada vez que cambia).

Contador que recuerda su valor al recargar

import { useState, useEffect } from "react";

function Contador() {
  // 1. Valor inicial: lee de localStorage (o 0 si no hay nada)
  const [conteo, setConteo] = useState(() => {
    const guardado = localStorage.getItem("conteo");
    return guardado ? JSON.parse(guardado) : 0;
  });

  // 2. Cada vez que 'conteo' cambia, lo guardamos
  useEffect(() => {
    localStorage.setItem("conteo", JSON.stringify(conteo));
  }, [conteo]); // ← se ejecuta solo si 'conteo' cambió

  return (
    <button onClick={() => setConteo(conteo + 1)}>
      Clics: {conteo}
    </button>
  );
}

El array de dependencias [conteo]

Le dice a useEffect "ejecútate solo cuando conteo cambie". Si pones [], corre una sola vez; si lo omites, corre en cada render.

El valor inicial como función

Pasar una función a useState(() => ...) hace que la lectura de localStorage ocurra solo una vez, no en cada render. Es más eficiente.
