Introducción a React

Hasta ahora escribiste JavaScript "a mano". React es la herramienta que usa la industria para construir interfaces grandes sin perder el control.

1. ¿Qué es un Framework?

Una librería es como una caja de herramientas: tú decides cuándo usar el martillo. Un framework es como la estructura de una casa prefabricada: te da una forma de trabajar y tú rellenas los espacios.

Técnicamente React es una librería, pero en la práctica con su ecosistema (router, build tools, estado) funciona como un framework. Lo importante: React resuelve un problema concreto que viste en el módulo del DOM.

El problema: DOM manual

Con document.querySelector debes buscar cada elemento y actualizarlo tú mismo. En una app grande esto se vuelve un caos imposible de mantener.

// JS puro: tú actualizas el DOM a mano
const el = document.getElementById("contador");
let n = 0;
boton.addEventListener("click", () => {
  n++;
  el.textContent = n; // actualización manual
});
La solución: React

Tú describes cómo se ve la UI según el estado. React se encarga de actualizar el DOM por ti cuando el estado cambia.

// React: describes el resultado, no los pasos
const [n, setN] = useState(0);
return (
  <button onClick={() => setN(n + 1)}>
    {n}
  </button>
);

2. El Virtual DOM

La clave del rendimiento de React es el Virtual DOM: una copia en memoria de la interfaz. Cuando algo cambia, React compara la copia nueva con la anterior y solo actualiza en pantalla lo que realmente cambió.

Idea central: UI = f(estado)

Tu interfaz es una función de su estado. No piensas en "cómo cambio este botón", piensas en "cómo se ve la app cuando el contador vale 5". React calcula el resto.

3. Tu Primer Proyecto con Vite

Vite es la forma recomendada hoy de crear un proyecto React. Necesitas tener instalado Node.js. Sigue estos comandos en la terminal:

1

Crea el proyecto. Esto genera una carpeta mi-app con la plantilla de React.

npm create vite@latest mi-app -- --template react

npm create vite@latest: descarga y ejecuta el asistente de Vite. mi-app: nombre de la carpeta. --template react: elige la plantilla de React (sin esto, te preguntaría interactivamente).

2

Entra a la carpeta del proyecto.

cd mi-app

cd (change directory): cambia tu ubicación en la terminal hacia la carpeta recién creada.

3

Instala las dependencias listadas en package.json.

npm install

npm install: descarga React y todas las librerías necesarias dentro de la carpeta node_modules. Solo se ejecuta una vez (o cuando agregas paquetes).

4

Arranca el servidor de desarrollo.

npm run dev

npm run dev: levanta un servidor local (normalmente en http://localhost:5173) con recarga en caliente. Cada vez que guardes, verás el cambio al instante.

Estructura del proyecto generado

mi-app/
├── node_modules/ # librerías instaladas (no se toca)
├── public/ # archivos estáticos (imágenes, favicon)
├── src/
│   ├── App.jsx # tu componente principal
│   ├── main.jsx # punto de entrada: monta React en el HTML
│   └── index.css # estilos globales
├── index.html # único HTML; React vive dentro del <div id="root">
└── package.json # dependencias y scripts (dev, build...)

React es una SPA: hay un solo index.html con un <div id="root"> vacío. main.jsx "inyecta" toda tu aplicación dentro de ese div.

4. Cómo se Conecta Todo

Estos dos archivos son el corazón de cualquier app React. main.jsx arranca todo; App.jsx es lo que ves.

main.jsx — punto de entrada
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

// Busca el div#root y monta <App/> dentro
createRoot(document.getElementById("root"))
  .render(<App />);
App.jsx — tu primer componente
function App() {
  return (
    <h1>¡Hola, React!</h1>
  );
}

export default App;
