APIs, JSON y Async

Las apps reales no inventan sus datos: los piden a un servidor. Aquí aprendes a traer datos de internet y mostrarlos en React.

1. ¿Qué es una API?

Una API es un servidor que responde peticiones por una URL. Tú pides datos a una dirección (endpoint) y te responde, casi siempre, en formato JSON.

Ciclo de una petición HTTP

💻

Tu app React

— GET /usuarios →

petición (request)

🗄️

Servidor / API

← JSON —

respuesta (response)

Un JSON de respuesta se ve así. Es texto con la misma forma que un objeto JavaScript:

{
  "id": 1,
  "nombre": "Ana López",
  "activo": true,
  "cursos": ["React", "CSS"]
}

Los verbos HTTP dicen qué quieres hacer: GET (leer), POST (crear), PUT (actualizar), DELETE (borrar).

2. Promesas y async/await

Pedir datos a internet toma tiempo. JavaScript no se queda esperando: sigue ejecutando y avisa cuando la respuesta llega. Ese "te aviso luego" es una promesa.

async/await nos deja escribir ese código de forma clara, como si fuera paso a paso.

Forma antigua: .then()
fetch(url)
  .then((res) => res.json())
  .then((datos) => {
    console.log(datos);
  })
  .catch((err) => console.error(err));
Forma moderna: async/await
async function cargar() {
  try {
    const res = await fetch(url);
    const datos = await res.json();
    console.log(datos);
  } catch (err) {
    console.error(err);
  }
}

Las 3 palabras clave

async marca una función como asíncrona. await pausa hasta que la promesa termina (solo dentro de funciones async). try/catch atrapa errores de red para que la app no se rompa.

3. fetch vs. axios

fetch viene incluido en el navegador. axios es una librería que se instala y simplifica varias cosas.

fetch (nativo)

Necesita un paso extra: convertir la respuesta a JSON con .json().

const res = await fetch("/api/usuarios");
const datos = await res.json();
axios (librería)

Convierte el JSON solo: los datos llegan en res.data.

const res = await axios.get("/api/usuarios");
const datos = res.data;

Para usar axios primero lo instalas en tu proyecto:

npm install axios

npm install axios: descarga la librería axios y la agrega a package.json. Luego la importas con import axios from "axios".

¿Cuál usar? Para proyectos pequeños, fetch sobra. Para apps grandes, axios ahorra código repetido (interceptores, base URL, manejo de errores).

4. Consumir una API en React

El patrón estándar: 3 estados (datos, cargando, error) + useEffect para pedir al montar el componente.

import { useState, useEffect } from "react";

function Usuarios() {
  const [datos, setDatos] = useState([]);
  const [cargando, setCargando] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    async function cargar() {
      try {
        const res = await fetch("https://jsonplaceholder.typicode.com/users");
        if (!res.ok) throw new Error("Fallo la petición");
        const json = await res.json();
        setDatos(json);
      } catch (err) {
        setError(err.message);
      } finally {
        setCargando(false);
      }
    }
    cargar();
  }, []); // [] = pedir solo una vez, al montar

  if (cargando) return <p>Cargando...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {datos.map((u) => <li key={u.id}>{u.name}</li>)}
    </ul>
  );
}
⏳

cargando

Muestra "Cargando..." mientras llega la respuesta.

✅

datos

Guarda la respuesta y la pinta con .map().

❌

error

Si la red falla, muestra un mensaje en vez de romperse.
