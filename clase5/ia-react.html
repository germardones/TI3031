IA en el Desarrollo

Dos aliados del desarrollador moderno: GitHub Copilot escribe código contigo; SonarQube vigila que ese código sea sano.

1. GitHub Copilot

Copilot es un "autocompletado inteligente": sugiere líneas o funciones completas mientras programas. En React acelera tareas repetitivas como crear componentes o llamadas a API.

⌨️

Autocompleta

Sugiere el resto de la línea o bloque. Aceptas con Tab.

💬

Chat

Le preguntas en lenguaje natural: "crea un hook para fetch".

🔧

Refactoriza

Explica, traduce y mejora código que seleccionas.

Instalación en VS Code

1. Abre la pestaña Extensiones (Ctrl+Shift+X) y busca "GitHub Copilot". Instálala.

2. Inicia sesión con tu cuenta de GitHub (gratis para estudiantes con GitHub Student Pack).

3. Empieza a escribir. Las sugerencias aparecen en gris: Tab acepta, Esc rechaza.

Cómo guiarlo: comentarios = instrucciones

Copilot lee tus comentarios. Un comentario claro produce mejor sugerencia:

// Componente que muestra una tarjeta de producto
// recibe props: nombre, precio, imagen
// con un botón "Agregar al carrito"

⚠ Tú eres el responsable, no la IA

Copilot se equivoca: inventa funciones, sugiere código inseguro o con bugs. Siempre lee y entiende lo que aceptas. Nunca pegues código que no comprendes. La IA acelera, pero no reemplaza tu criterio.

2. SonarQube

SonarQube es un "inspector de calidad" automático. Hace análisis estático: lee tu código y reporta problemas antes de que lleguen a los usuarios.

🐞 Bugs

Errores lógicos: variables sin usar, comparaciones que siempre dan falso.

🔓 Vulnerabilidades

Riesgos de seguridad: XSS, claves expuestas, inyección de código.

🧹 Code Smells

Malas prácticas que no rompen, pero hacen el código difícil de mantener.

📊 Cobertura

Mide cuánto de tu código está cubierto por pruebas (tests).

La forma fácil: SonarLint en VS Code

Para empezar, no necesitas instalar el servidor completo. SonarLint es la extensión que analiza mientras escribes:

1. En VS Code, Extensiones (Ctrl+Shift+X), busca "SonarLint" e instala.

2. Subraya los problemas directamente en el editor, como un corrector ortográfico para tu código.

3. Pasa el cursor sobre el subrayado para ver qué está mal y cómo arreglarlo.

Análisis del proyecto completo (avanzado)

Para escanear todo un proyecto contra un servidor SonarQube se usa el sonar-scanner:

sonar-scanner -Dsonar.projectKey=mi-app

sonar-scanner: ejecuta el análisis. -Dsonar.projectKey: identifica tu proyecto en el servidor. El resultado aparece en un panel web con el reporte de calidad.

Copilot + SonarQube: el flujo ideal

Copilot te ayuda a escribir rápido; SonarQube verifica que lo escrito sea seguro y limpio. Uno acelera, el otro protege. Juntos = código profesional.

3. Usar IA con Criterio

✓ Buenas prácticas

  • • Lee y entiende cada sugerencia antes de aceptar.
  • • Pídele que explique el código que genera.
  • • Úsalo para tareas repetitivas y boilerplate.
  • • Verifica con SonarLint lo que la IA escribió.
  • • Escribe comentarios claros para guiarlo mejor.

✗ Errores comunes

  • • Pegar código sin entenderlo.
  • • Confiar ciegamente: la IA inventa funciones.
  • • Aceptar credenciales o claves que sugiera.
  • • Dejar de aprender los fundamentos.
  • • Ignorar las alertas de seguridad.
